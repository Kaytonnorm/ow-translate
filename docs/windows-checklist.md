# Windows 手动验证清单

> 开发在 macOS，以下所有项均**未在 Windows 实机验证**。每完成一项请把结果
> （通过/失败/现象截图/日志）记录到该项下方，并同步更新 AGENTS.md 的验证状态表。

## 阶段 1：OCR + 翻译 CLI

### 1. 环境安装
- [ ] 按 docs/paddle-windows-notes.md 装好 Python 3.12、VC++ Redist、依赖。
- [ ] `python -c "import paddle, paddleocr; print(paddle.__version__, paddleocr.__version__)"` 输出 `3.0.0 3.7.0`。
- 预期：无 DLL 报错；首次运行 OCR 时自动下载模型（约 20MB）。

### 2. 图片识别（核心链路）
- [ ] 把 1~2 张真实游戏聊天截图放入 `samples/real/`（注意该目录不入 git）。
- [ ] 运行 `python backend\main.py --image samples\real\<截图>.png`
- 预期：输出每行原文+置信度+中文译文；置信度低于 0.6 的行被过滤。
- 需记录：准确率如何、有哪些典型错字（用于后续调预处理/术语表）。

### 3. 实时截屏 + DPI 缩放（重点）
- [ ] 显示设置为 100% 缩放：用系统截图工具量出聊天框区域，运行
  `python backend\main.py --region "x,y,w,h"`，确认识别内容正确。
- [ ] 显示设置为 **125%**：重复上述步骤，确认识别的仍是目标区域。
- [ ] 显示设置为 **150%**：同上。
- 预期：三种缩放下 `--region` 坐标语义一致（都传物理像素）；
  若错位，日志中会出现「截图尺寸与请求不符」警告，请回传该日志。
- [ ] 多显示器：把游戏放副屏，用负坐标（如 `-1920,0,...`）截取副屏区域验证。

### 4. 性能
- [ ] 记录单帧 OCR 耗时（日志「OCR 完成 … 耗时」）。
- 预期：聊天框小图 CPU 上约 0.3~2s；若 >5s 记录 CPU 型号与日志。

### 5. 通用
- [ ] 项目路径不含中文/空格时一切正常（含中文路径也测一下，代码已用
  `np.fromfile` 兼容，但需实机确认）。
- [ ] 杀毒软件（Defender/第三方）运行期间是否出现拦截提示。

## 阶段 4 预置：悬浮窗（届时验证）

- [ ] Electron 悬浮窗设置 `setAlwaysOnTop(true, "screen-saver")` 高置顶层级，
  在**无边框全屏**游戏画面上方是否可见。
- [ ] 鼠标穿透开启后，点击悬浮窗区域是否落到游戏上（是否穿透成功）。
- [ ] 全局快捷键在游戏获得焦点时是否仍生效。
- [ ] 125%/150% 缩放下悬浮窗位置与截图区域是否对齐。
